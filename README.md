# AptiTrack — Aptitude Preparation Tracker

A simple personal preparation website containing:
- Full TCS NQT aptitude syllabus as a checklist
- Automatic overall and section-wise progress
- Study timer with topic selection
- Study-time history
- Daily study goal
- 7-day study activity/streak
- Local browser storage (no account/backend required)

## Run
Open `index.html` directly in Chrome/Edge.

## Data
Progress and study sessions are saved in the browser's localStorage. Clearing the browser's site data will clear the saved tracker data.
